## 🛠️ Prerequisites & Installation Guide

Before starting our AI/ML journey, the following foundational tools must be installed and configured on your system:

### 1. Python Installation
Python is the core programming language used throughout this course for data science, machine learning, and AI application development.

- **Download Link (Windows / Mac / Linux):** [python.org/downloads](https://www.python.org/downloads/)
- **Installation Steps (Windows):**
  1. Download the latest stable Python 3 installer from the official link above.
  2. Launch the installer.
  3. ⚠️ **Important:** Check the box that says **"Add python.exe to PATH"** at the bottom before clicking *Install Now*.
  4. Complete the installation and close the installer.
- **Verification:**
  Open a terminal (PowerShell or Command Prompt) and run:
  ```bash
  python --version
  pip --version
  ```

---

### 2. Visual Studio Code (VS Code)
VS Code is our primary code editor for writing scripts, managing projects, and running terminals.

- **Download Link (Windows / Mac / Linux):** [code.visualstudio.com/download](https://code.visualstudio.com/download)
- **Setup & Recommended Extensions:**
  1. Install VS Code following default installation prompts.
  2. Open VS Code and open the Extensions view (`Ctrl + Shift + X`).
  3. Install recommended extensions:
     - **Python** (by Microsoft) – Intellisense, linting, and debugging.
     - **Pylance** – High-performance language support for Python.
     - **Jupyter** – Interactive notebook execution for data science experiments.

---

- Connect local workspace with GitHub repository: [PRIME-AI-ML-Course](https://github.com/CadetTech2/PRIME-AI-ML-Course)
- Daily workflow: Commit code and progress notes at the end of each session.

### Syllabus Breakdown:

1. **Foundations & Core Tooling**
   - **Python Programming:** Syntax, data structures, OOP, file handling.
   - **Data Pre-processing & Visualization:** Cleaning datasets, feature scaling, Matplotlib, Seaborn.
   - **Math for AI:** Linear algebra, statistics, and probability distributions.
   - **SQL for Data Science:** Relational queries, joins, and data manipulation.

2. **Machine Learning & Model Evaluation**
   - **Supervised Learning:** Linear Regression, Logistic Regression, Support Vector Machines (SVM), Decision Trees.
   - **Unsupervised Learning:** K-Means clustering, hierarchical clustering, association rules.
   - **Reinforcement Learning:** Agents, rewards, environments, and policies.
   - **Model Metrics & Diagnostics:** Confusion Matrix, Precision, Recall, F1 score, ROC-AUC, Bias-Variance tradeoff.

3. **Deep Learning & Neural Architectures**
   - **Foundations:** Perceptron, activation functions, loss functions, backpropagation.
   - **Architectures:** Feedforward Neural Networks (FNN), Convolutional Neural Networks (CNN), Recurrent Neural Networks (RNN).
   - **Advanced Architectures:** Transformers and Attention mechanisms.
   - **Frameworks:** TensorFlow & Keras.

4. **Generative AI, LLMs & Advanced AI**
   - **NLP & LLMs:** Text tokenization, embeddings, language modeling, prompt engineering.
   - **Modern GenAI Workflows:** Retrieval-Augmented Generation (RAG) and OpenAI APIs.
   - **Generative Models:** Generative Adversarial Networks (GANs).

5. **Deployment, DevOps & Projects**
   - **AI Deployment:** Serving models with Flask REST APIs.
   - **Containerization & Scale:** Docker and Kubernetes.
   - **Portfolio Projects:** Multiple hands-on minor and major projects.
