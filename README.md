## 🗺️ Course Curriculum & Roadmap

The course covers a comprehensive journey from core foundations to advanced modern AI:

- **Programming & Foundations:** Python, Data Pre-processing, Data Visualization, Math for AI (Statistics & Probability), SQL for Data Science.
- **Machine Learning:** Supervised Learning (Regression & Classification, Logistic Regression, SVM, Decision Trees), Unsupervised Learning (Clustering, K-Means, Association), Reinforcement Learning, Bias/Variance Tradeoff, Model Evaluation (Precision, Recall, F1).
- **Deep Learning & Architectures:** Perceptron, FNN, CNN & RNN Architectures, Transformers, TensorFlow.
- **Generative AI & LLMs:** Generative AI (GenAI), Large Language Models (LLMs), Natural Language Processing (NLP), Retrieval-Augmented Generation (RAG), OpenAI APIs, Generative Adversarial Networks (GAN).
- **AI Deployment & DevOps:** Flask (Web Development with AI), Git & GitHub, Docker, Kubernetes.
- **Practical Experience:** Multiple minor and major hands-on projects.
